# 智能照明方案馆 采集工具

Python 3.11 + requests + beautifulsoup4 + lxml + pandas

## 依赖

```txt
requests>=2.31
beautifulsoup4>=4.12
lxml>=5.1
pandas>=2.1
playwright>=1.40
```

## 安装

```bash
python3.11 -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

# playwright 需额外安装浏览器
playwright install chromium
```

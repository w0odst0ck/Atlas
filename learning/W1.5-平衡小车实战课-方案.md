## 六课设计（每课 = 读代码 + 改代码 + 实机验证）

| 课 | 主题 | 可验证物（改什么→看什么→通过标准） | 照明迁移 |
|----|------|--------------------------------------|---------|
| 1 | 系统解剖：架构图 + FreeRTOS 任务识别 | 画出任务/队列/数据流图；改一个任务优先级看行为变化 | 网关多设备调度 |
| 2 | I2C + MPU6050（DMP 姿态解算） | 串口打印原始 vs DMP 角度；改采样率看稳定性 | 光照传感器读取 |
| 3 | PWM 电机驱动（TIM/占空比/方向） | 改占空比 → 转速变化可测 | 调光驱动（W3 兑现） |
| 4 | PID 直立控制（直立/速度/转向环） | 对照实验调参（只改一个参数→记录振荡/过冲→成表） | 恒照度闭环（W3 兑现） |
| 5 | 通信链路：UART 蓝牙 + OLED 调试 | 改帧格式/波特率；蓝牙指令控制演示 | DALI 链路思维（W2 兑现） |
| 6 | 找 bug + 改进 + 毕业评审 | 找到作者埋的坑并修复；现场演示+讲解 | 讲清楚灯怎么恒光 |

## 细节优化条款（全收）

### A. 工程纪律
1. **基线快照**（开课前）：备份当前固件 + 记录关键参数（PID 三环/电机方向/I2C 地址）+ 跑通状态 → 每课可回滚
2. **代码 git 化**：确认烧录版本（v0.0/v0.1）→ 解压入本地 git 仓 → 每课一个 commit
3. **时间盒**：3 周（8 月底），到点未完成也走毕业评审（用已完成部分）

### B. 学习设计
4. **可验证物必填**：每课"改什么→看什么→通过标准"，无验证物不算课
5. **PID 调参 = 对照实验**：只改一个参数，现象成表沉淀进 quiz（量化背景方法论复用）
6. **新旧映射（摸底锚点）**：开课第一节建表 `digitalWrite↔HAL_GPIO_WritePin`、`ledcWrite↔__HAL_TIM_SET_COMPARE`、`delay↔vTaskDelay`（手册 §0 认知锚点）

### C. 目标衔接
7. **照明迁移专节**：手册专节"能力→照明落点→兑现时间（指向 W2/W3 课次）"，W2/W3 开课时回来兑现
8. **毕业评审实操化**：现场改参数看车倒不倒 + 必答问题 + 钩子池抽题（模拟给客户演示方案）

## 必答问题（毕业验收清单，开课倒推）

1. 这辆车由哪几个子系统组成？数据怎么流动？（架构）
2. MPU6050 的 DMP 解算解决了什么问题？（传感）
3. PID 三环各管什么？调参顺序为什么是直立→速度→转向？（控制）
4. FreeRTOS 里任务怎么通信？为什么用队列不用全局变量？（RTOS）
5. 电机 PWM 为什么会造成 EMI？怎么处理？（EMC 种子）

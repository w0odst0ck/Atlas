# D1 · GPIO 输出

> 场景：ESP32 点灯 demo（F 仓 `labs/w1/D1-blink/`）。日期：2026-08-06。体系：pair-learning v2（D 级三件套）

**一句话本质**：`digitalWrite` 不是"给电压"，是**写寄存器**——`GPIO_OUT_REG |= (1<<2)`，推挽结构把引脚物理接到电源轨。

**讲解**：芯片内部推挽（两个 MOSFET）：HIGH=上管导通推上 3.3V、LOW=下管导通拉下 0V，纳秒级响应。LED 是**电流器件**（正向压降 ≈2V → 220Ω 限流 → 6mA），电阻 = 限流器，不串瞬间烧毁。逻辑电平（3.3V）由芯片供电/制程决定，与外部电阻无关。

**类比**：寄存器写 bit = dict 操作 / 位掩码的放大版（编程基础，画像库）。

**关键点**：
- 嵌入式本质 = 读写寄存器
- LED 电流器件：决定生死/亮度的是电流不是电压；电阻 = 限流器（220Ω → 6mA）
- 逻辑电平 ≠ 电阻分压：3.3V 是芯片供电/制程决定，混接需 level shifter（W2 RS-485 会遇到）
- pinMode 必须先于读写（不配模式直接写 = 未定义行为）

**项目落点**：控制层"灯亮/灭"最基本执行单元——LED = 一盏灯的抽象，智能照明执行层从写寄存器开始。

## 题目卡片

### T1 digitalWrite 内部（寄存器 + 推挽）
**题目**：`digitalWrite(LED_PIN, HIGH)` 芯片里发生了什么？
**标准/记忆点**：
- 本质 = **写寄存器**：`*(GPIO_OUT_REG) |= (1<<2)` 输出寄存器 bit2 置 1；Arduino 函数只是封装
- 推挽两个 MOSFET：HIGH=上管导通推上 3.3V 电源轨，LOW=下管拉 0V；纳秒级物理接通
- 记忆点：**嵌入式本质 = 读写寄存器**
**作答史**：
- 2026-08-06 ✅ 推演方向正确：写入寄存器 + 推挽接通电源（批次 1 Q1）
**状态**：✅

### T2 LED 限流（电流器件）
**题目**：LED 为什么必须串 220Ω 电阻？不串会怎样？
**标准/记忆点**：
- LED 是**电流器件**：正向压降 ≈2V → 电阻分 1.3V → 电流 = 1.3/220 ≈ **6mA**（额定 20mA 安全）
- 不串 = 3.3V/0Ω ≈ 无穷大瞬间烧毁
- 记忆点：**电阻 = 限流器**（LED 的保镖）
**作答史**：
- 2026-08-06 ✅ 限流方向对（批次 1 Q2）
**状态**：✅

### T3 逻辑电平 vs 电阻分压
**题目**：为什么 HIGH 是 3.3V，不是 5V？
**标准/记忆点**：
- **逻辑电平 ≠ 电阻分压**——HIGH=3.3V 是芯片 I/O 电压（供电/制程决定），电阻分压是外部电路，两个层面
- 3.3V=现代低功耗主流；5V=TTL 时代遗产
- 混接坑：3.3V 接 5V 烧芯片、5V 读 3.3V 读不到 → level shifter
- 记忆点：**电平规格是芯片出厂定的，不是电路分出来的**——数字看阈值，模拟看比例
**作答史**：
- 2026-08-06 ⚠️ 半对：误答「电阻分压」（概念混淆），纠正后回收（批次 1 Q3）
- 2026-08-19 ✅ 直考通过：电平=芯片供电/制程决定，分压=模拟量层面（W1 收口）
**状态**：✅

### T4 PWM 占空比调光（深入一问）
**题目**：LED 阳极直连 3.3V 永远亮，为什么不是可行的调光方案？
**标准/记忆点**：
- 这就是 **PWM/占空比**：控制高低电平占比 → 平均光能变化 → 亮度变化
- 视觉暂留（~60Hz 以上无闪烁，LED 驱动通常 1kHz+）；50% 占空比 = 看起来半亮
- 真实调光驱动底层就是 PWM（DALI/0-10V 只是上层协议，W3 深挖）
- 记忆点：**亮度 = 平均光能 = 满亮 × 占空比**

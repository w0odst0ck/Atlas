### T1 占空比 vs 频率（独立维度）
**题目**：占空比 1% 灯什么样？频率 1kHz→20Hz 又会怎样？
**标准/记忆点**：
- 占空比 = 亮度旋钮：1% ≈ 灭但 **0% 才真灭**（平均光能 = 满亮 × 占空比）
- 频率 = 闪烁消除器：20Hz < 视觉暂留下限（~60Hz）→ 频闪（头晕/相机频闪带，IEEE 1789——智能照明/EMC 行业指标）；≥1kHz 不可见
- 数学上占空比定义在周期内有耦合，功能上独立——调一不动另一
- 记忆点：**亮度旋钮（占空比）+ 闪烁消除器（频率），各管各**
**作答史**：
- 2026-08-07 ✅ 两个维度都答到（批次 1 Q1）
- 2026-08-14 ✅ 复检通过：独立 + 亮度/闪烁映射全对（W1-5，上次卡壳已回收）
**状态**：✅

### T2 调光三选（PWM vs 调流）
**题目**：为什么行业不用「直接调小电流」的模拟调光来规避 PWM 的 EMI 问题？
**标准/记忆点**：
- 调流 = **色温漂 + 损耗大**（原理级无解）：电流变化 → 波长漂移（蓝光芯片+荧光粉）→ 调暗颜色跟着变；损耗量化 = (V_in−V_LED)×I 全变热，越暗越差
- PWM 恒流 = 电流不变 → 色温/光效恒定；开关电源效率 90%+
- EMI 是工程问题（频率抖动/软开关/滤波器可修），色温/效率是原理问题（无解）
- 记忆点：**EMI 能修，色温不能修——选「原理级优点+工程级缺点」的路**
**作答史**：
- 2026-08-07 ✅ 色温 + 损耗全答到（批次 1 Q2）
**状态**：✅

### T3 分辨率与感知均匀（韦伯-费希纳）
**题目**：分辨率 8bit vs 16bit，为什么低亮度档位跳变可见、高亮度看不出？
**标准/记忆点**：
- 本质 = **韦伯-费希纳定律**：感知 ∝ log 光强（人眼对数感知——暗处放大/亮处压缩）
- 矛盾链条：编码**均匀分档** × 人眼对数感知 = 低端每档翻倍级跳变、高端 0.5% 无感（1→2 相对 +100% 可见；200→201 +0.5% 无感）
- 行业解法：gamma/非线性调光曲线（软件 LUT 最常见 / DALI 自带对数 / 硬件 16bit）
- 记忆点：**目标不是光强均匀，是感知均匀**

### T4 ledcWrite vs digitalWrite（硬件 offload）
**题目**：ledcWrite vs digitalWrite 本质区别？digitalWrite 硬写 1kHz 呼吸灯会怎样？
**标准/记忆点**：
- digitalWrite = CPU 每周期亲自翻转（写寄存器指令）；ledcWrite = CPU 写一次比较值（CCR），**定时器外设后台自动翻转**（硬件 offload）
- 小修正：ledcWrite 不是完全不需要 CPU——CPU 参与**一次**（下单），只是不参与每周期翻转
- 1kHz 呼吸灯致命的是**周期性实时要求**（每 500μs 精确翻转一次，期间不能被打断太久）→ 中断推迟翻转 → 占空比/频率抖动（呼吸灯变「咳嗽灯」）
- 类比：ledcWrite = webhook 式 vs digitalWrite = 轮询式（画像库，2026-08-11）
- 记忆点：**CPU 只下单，外设干活**
**作答史**：
- 2026-08-07 ✅ 抓住「谁在干活」（CPU vs 外设）本质，小修正：CPU 参与一次下单（批次 1 Q5）
**状态**：✅

# D4 · UART 通信

> 场景：UART 双实例互发 loopback demo（F 仓 `labs/w1/D4-uart/`，**留例**）。日期：2026-08-11。体系：pair-learning v2（D 级三件套）

**一句话本质**：UART 是**异步**串行通信——**没有时钟线**，收发双方靠"约定波特率 + 帧结构"自己对齐时序。

**讲解**：
- **波特率 = 约定语速**（bit/s，9600/115200 常见）：每个 bit 的时长 = 1/波特率（9600 → ≈104μs）。接收端从起始位下降沿开始，按这个间隔采样电平。**两端不一致 = 采样点错位 → 乱码**（不是"慢一点"，是采样节奏错，bit 边界对不上）
- **帧结构 = 话头话尾标记**（帧边界答案）：
  ```
  | 起始位(1, 低) | 数据位(5-8) | 校验位(可选) | 停止位(1-2, 高) |
  ```
  空闲时总线**保持高电平** → 起始位**下降沿** = "我要开始说话了"（帧起点）；停止位**高电平** = "这句说完了"（帧终点）。帧边界 = 起始位+停止位包出来的一个字节，不是靠超时猜
- **不丢数据机制**：硬件 FIFO（环形缓冲）——字节先进缓冲区，主循环 `available()` 查有货再 `read()`。呼应 D2：**硬件缓冲 = 生产者，主循环 = 消费者**，不让 CPU 忙等
- **Serial vs Serial2**：Serial 走 USB 转串口芯片（PC 可见，调试）；Serial2 是芯片内部 UART（TX2=D17/RX2=D16，连真实设备）

**类比**：UART = 约定好语速的对话（无节拍器）；帧 = 一句话——"喂"（起始位）引起注意 + 句号（停止位）收尾；波特率不一致 = 语速不同，全听岔（画像库）。

**关键点**：
- 波特率不一致 = 采样错位乱码，不是"慢"
- 帧边界 = 起始位下降沿（空闲高电平 → 低）开帧 + 停止位高电平收帧
- available() 先查后读（read 空缓冲返回 -1 易误判）
- 全双工：TX/RX 独立走线；loopback = 串口调试第一课（先确认能收到自己发的）
- 接线 TX↔RX 交叉是 UART 联调最常见错误（TX 对 TX = 两个发送端对顶）

**项目落点**：通信层——Modbus/RS-485 的物理基础（W2 兑现）；平衡车蓝牙遥控 = 现成 UART 实战对象（W1.5 拆它）。

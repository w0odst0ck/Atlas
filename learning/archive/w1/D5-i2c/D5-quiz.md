## 题目卡片

### T1 同步 vs 异步
**题目**：I2C 和 UART 的本质区别？为什么 I2C 不需要「波特率一致」？
**标准/记忆点**：
- I2C 同步：SCL 时钟线给接收方「**现在该读一位**」的节拍，跟着时钟采样即可 → 不需要约定波特率
- UART 异步：无时钟线，只能靠约定的每 bit 时长（1/波特率）自己采样
- 小纠正：起始/结束不是时钟直接控制，是 SDA/SCL 的**特殊电平组合**（起始 = SCL 高时 SDA 下降沿；停止 = SCL 高时 SDA 上升沿）——时钟管采样节奏，起始/停止是独立信号
- 记忆点：**同步 = 时钟拍节奏，异步 = 自己数拍子**
**作答史**：
- 2026-08-11 ✅ 时钟线 vs 无时钟线，核心抓住（批次 1 Q1）
**状态**：✅

### T2 地址点名 + ACK
**题目**：一条 I2C 总线上挂 3 个设备，怎么保证「只有目标设备在听」？
**标准/记忆点**：
- 主机先发「设备地址 + 读/写位」——**地址匹配的从机拉低 SDA 回 ACK 应答**（主机确认「有人在家」），然后才开始传数据
- 不匹配的设备不响应、继续监听总线等自己的地址
- 类比：教室点名——喊到学号才答到（ACK）；设备地址 ≈ 端口号（画像库）
- 记忆点：**点名机制 —— 喊到学号才答到（ACK）**
**作答史**：
- 2026-08-11 ✅ 地址匹配机制全对（批次 1 Q2）
**状态**：✅

### T3 寄存器读链
**题目**：为什么说「读写寄存器」是嵌入式主线？MPU6050 读数到 getEvent() 经历了什么？
**标准/记忆点**：
- 完整链 = 物理感应 → **ADC**（MEMS 物理量 → 模拟信号 → 模数转换 → 数字值）→ 存入内部寄存器（按**寄存器地址**：ACCEL_XOUT_H/L、GYRO_*、TEMP——主机要发地址才知道读哪个）→ I2C 读协议（设备地址+寄存器地址+读命令）→ 从机值上 SDA → 库封装 getEvent() → 变量
- 纠正：传感器不是「接受信号存寄存器」——是**把物理量转换成数字**存进寄存器（采集器不是转发器）
- 记忆点：**传感器 = ADC + 寄存器表，库 = 读寄存器的封装**
**作答史**：
- 2026-08-11 ⚠️ 半对：寄存器核心+方向对，缺 ADC 和寄存器寻址两环（批次 1 Q3）
**状态**：✅（读链要能口述完整链条）

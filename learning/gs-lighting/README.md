# GS-Lighting 项目伴随学习 · 学习地图

> 模式：**项目 ↔ 学习双向闭环**——做项目遇到知识缺口 → 登记本地图 → 学习单元 → 反哺提案改项目。
> 范式：**pair-learning v2.3**（对话式教学 · 互动即沉淀 · 三件套 · 微题 3 道 · 类比必查）；本目录 = 阶段，U{N} = 交付单元。
> 项目代码在 F 仓（WSL：`projects/Forge/gs-lighting/`）；学习文档在此（A 仓，Obsidian 可读）。
> 设计文档见 `Atlas/plan/gs-lighting/技术方案-v1.1.md`；项目日志见 `Forge/memory/`。

## 单元结构（每 U = 一个目录，三件套，对齐 pair-learning）

```
U{N}-{主题}/              # 每 U 一个目录
├── U{N}-{主题}.md        # 手册：认知锚点/必答问题/每课（场景+本质+讲解+类比+关键点+项目落点+微题+钩子）/总览图/钩子池/误解纠正/费曼
├── U{N}-quiz.md          # 复习手稿：题目卡片制（题目/标准/作答史/状态）
└── U{N}-review.md        # 复盘：学习路径/踩坑/项目落地追踪/教学决策
```

> 模板：`../agent-skills/pair-learning/templates/`（00-手册/00-quiz/00-review）。本地微调：手册内「项目落点」字段强调知识缺口/验证物/反哺提案（项目伴随学习特色）。

## 闭环流程（对齐 skill 会话流程）

1. 开场双查：PLAN/review-checklist.md §网络+边缘 到期条目 + 本地图当前单元
2. 开 U 单元：建三件套（模板复制）→ 一课四件套交付（场景+知识点+项目落点+3 微题一次给全）
3. 作答 → **当轮批改**（判定三件套 + 点评四步）→ quiz 卡片追加作答史 + 手册误解纠正/类比回写
4. 学完写反哺提案 → PLAN/飞轮.md 提案队列 → collab-flow 落地 F 仓 → 验证物出现 → 闭环
5. 收尾四步：进度更新 + checklist + 日志 + commit（前缀 atlas:）

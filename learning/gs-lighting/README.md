## 单元模板（四段）

见 `单元模板.md`。每单元 = ① 知识缺口 ② 学习内容 ③ 验证物 ④ 反哺提案。

## 闭环流程

1. 项目推进卡壳/发现缺口 → 代码 TODO 标注 + 本地图登记
2. 开学习单元（pair-learning 互动：先讲→检验→点评→沉淀）
3. 学完写反哺提案（改项目什么、怎么改）→ 飞轮.md 提案队列
4. collab-flow 或直改落地 F 仓代码 → 验证物出现 → 单元 ✅

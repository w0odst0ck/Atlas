# U 单元模板说明（项目伴随学习 · 对齐 pair-learning v2.3）

> 模板真源：`../agent-skills/pair-learning/templates/`（00-手册.md / 00-quiz.md / 00-review.md）——复制改名即用。
> 本文件只记录**本地微调点**（范式跟 skill，模板微调允许）。

## 建单元步骤

```bash
# 每 U 一个目录（对齐 D{N}-{主题}/）
mkdir "U{N}-{主题}"
# 复制 skill 模板
cp ../agent-skills/pair-learning/templates/00-手册.md "U{N}-{主题}/U{N}-{主题}.md"
cp ../agent-skills/pair-learning/templates/00-quiz.md  "U{N}-{主题}/U{N}-quiz.md"
cp ../agent-skills/pair-learning/templates/00-review.md "U{N}-{主题}/U{N}-review.md"
```

## 本地微调点（仅这些，其余照 skill）

1. **手册 §项目落点**扩展为项目伴随学习特色四字段：
   - ① 知识缺口：项目哪个模块触发（如 mesh.py 信道建模）
   - ② 学习内容：知识点 + 对应 U 地图条目
   - ③ 验证物：在项目里能看到什么（通过标准）
   - ④ 反哺提案：学完改项目什么（→ 飞轮提案队列）
2. **阶段命名**：U{N}（U = 交付单元，对齐 D{N}）；阶段 = gs-lighting 项目伴随学习
3. **quiz 卡片**：题目从项目场景出发（场景本身就是答题线索）

## 硬性规则（skill 原文，违反即被点名）

- 一课 3 道微题（不多不少）
- 互动即沉淀：答完同一轮回复内写入 quiz
- 类比必查画像库 + 新类比当轮回写（grep 可查）
- 开课门禁：上一课批次沉淀完成才开下一课
- 一次一个认知单元

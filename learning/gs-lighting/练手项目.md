# GS-Lighting 路径 · 练手项目清单（开源 · 低成本）

> 需求：能练手的**完整开源项目**，不是库。成本优先：模型仿真（≈0 元）→ 小成本硬件（≤1000 元）。
> 适配路径：物联网工程师 + 边缘计算 AI（网络连接层 → 边缘 AI 计算层）。
> 全部经 GitHub API 查证（2026-08-20，活跃）。反哺映射 = 与 gs-lighting / 学习地图 U 单元的关系。

## 三、推荐路线（预算核算 ≤1000 元 ✅）

```
阶段 1（现在，0 元）：ns-3 实验 + gs-lighting M1-M3 + TinyML 量化流水线（PC 模拟）
阶段 2（Phase 2，≈250 元）：gs-lighting 硬件包（ESP32-S3+雷达+光感）——项目落地 + 边缘 AI 入门双用
阶段 3（可选 +60 元）：ESP32-CAM 视觉节点（补视觉模态，雷达+视觉多传感器融合）
阶段 4（可选 +150 元）：Meshtastic LoRa（网络层真实对照，社区活跃）
────────────────────────────────────────
最低方案：250 元（只做 1+2）｜推荐方案：400 元（1+2+3）｜全配：550 元
```

## 四、原则

1. **仿真先行**：每个硬件项目先有仿真版（gs-lighting 模式），验收过再买件
2. **一个项目多模态**：优先选能同时练「网络 + 边缘 AI」的（如 gs-lighting 硬件包、ESP32-CAM 视觉节点）
3. **复用优先**：平衡小车车体、3060 GPU 主机、本地 model_server 都是现成资产
4. **开源优先**：全部选活跃社区项目，踩坑有答案

# 练手项目清单 · 聚焦版（边缘 AI + 网络 + 硬件 Agent）

> 方向：物联网工程师 + 边缘计算 AI，后续考虑**硬件 Agent 研发**（感知 → 大脑 → 执行 → 联网的边缘智能体）。
> 原则：少而精、仿真先行、小成本（≤1000 元）、一个项目多模态。
> 全部经 GitHub API 查证（2026-08-20）。

## 主线：硬件 Agent 研发路径

```
感知（雷达/视觉/语音）→ 大脑（TinyML 量化模型 + 本地小 LLM）→ 执行（灯/喇叭/屏）→ 联网（Mesh/MQTT）
```

| # | 项目 | 成本 | 练手点 | 在 Agent 里的角色 |
|---|---|---|---|---|
| 1 | **gs-lighting 本体 + ns-3 校准**（仿真，0 元） | 0 | 网络建模（CSMA/CA/路由）+ 节能策略 | 网络层理解 + 项目主线 |
| 2 | **gs-lighting Phase 2 硬件包**（ESP32-S3×4+LD2410+BH1750） | ≈250 元 | 雷达存在检测 + 恒照度闭环 + MQTT 上云 | 感知节点（雷达/光感） |
| 3 | **ESP32-CAM 视觉节点**（esp32-camera + esp-dl/TFLite Micro） | ≈60 元 | 本地人/车检测 + int8 量化部署 | 感知节点（视觉） |
| 4 | **ESP32-S3 语音 Agent 原型**（INMP441 麦 + MAX98357 喇叭 + esp-skainet 唤醒 + 云端 LLM/本地小模型） | ≈150 元 | 语音唤醒 → LLM 决策 → 语音/屏幕/灯执行 | **Agent 雏形（大脑+执行）** |
| 5 | **RK3588 边缘 Agent 盒子**（Orange Pi 5 + llama.cpp 跑 Qwen 小模型，进阶） | ≈700 元 | 本地小 LLM + 视觉/语音多模态 Agent | **真正本地 Agent 大脑**（后期） |

## 预算

- **核心三件（2+3+4）= 460 元** ← 千元内 ✅，先做这条线
- 进阶（5）= 700 元，Phase 后期单独投入（或二手/降价再入）

## 为什么是这几件（去掉了什么）

- **gs-lighting 硬件包**：项目验收 + 感知层双用（雷达+光感 = Agent 的多模态感知入口）
- **ESP32-CAM（60 元）**：视觉模态成本极低，与雷达融合 = 多传感器 Agent 起点
- **语音 Agent 原型（150 元）**：把 LLM 决策接进硬件 = **硬件 Agent 的最小闭环**（这是你方向的第一个实体）
- **RK3588 盒子（700 元）**：llama.cpp 本地推理，摆脱云端依赖 = 真·边缘 Agent
- 已去掉：智能家居/OpenThread/LoRa/EdgeCloudSim/Scapy 工具（与主线无关，需要时再捡）

## 执行建议

1. **现在（0 元）**：gs-lighting M1-M3 + ns-3 实验 + TinyML 量化流水线（PC 模拟）
2. **Phase 2（250 元）**：gs-lighting 硬件包验收 → 雷达+恒照度闭环
3. **+60 元**：ESP32-CAM 视觉（补视觉模态，多传感器融合）
4. **+150 元**：语音 Agent 原型——**第一个硬件 Agent 闭环诞生**
5. **后期**：RK3588 盒子（本地小 LLM，Agent 大脑本地化）

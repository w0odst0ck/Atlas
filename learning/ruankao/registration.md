# 软考 · 报名全流程（2026 下半年）

**版本**: v1.0 | **日期**: 2026-08-05 | **考试**: 10/24-27

---

## 0. 关键事实

- **平台**：全国统一网上报名 → https://bm.ruankao.org.cn （中国计算机技术职业资格网）
- **时间**：各省报名窗口不同，下半年一般 **8 月中下旬陆续开放，9 月上中旬截止**（部分省只开 7-10 天，必须盯公告）
- **费用**：约 100-300 元/人（各省不同，中级一般 2 科合计 200 元左右），**缴费成功才算报名成功**
- **资格**：无学历/专业/工作经验限制，在校生可报
- **考区规则（在校生）**：本校设有报考点 → 必须在本校考区报；本校无报考点 → 在省软考办指定考区报

## 1. 时间线（2026 下半年）

| 日期 | 事项 |
|------|------|
| 现在 - 8 月中 | 注册平台账号、备照片、确认考区规则 |
| 8 月中下旬起 | **各省报名窗口陆续开放**（每日刷本省软考办公告） |
| 窗口期内 | 完成报名 + 缴费（不要拖到最后一天，防系统拥堵/截止） |
| 10 月中（考前一周） | 打印准考证（平台下载，需自行打印） |
| 10/24-27 | 考试（上下午各一场，具体日期以准考证为准） |
| 12 月左右 | 查成绩（ruankao.org.cn 首页） |
| 次年 1-3 月 | 领证（电子证书先行，纸质证书按省软考办通知领取） |

## 2. 报名步骤（窗口开放后）

1. **登录** https://bm.ruankao.org.cn，注册/登录账号（手机号 + 身份证）
2. **选择考区**：按第 0 节规则选（在校生优先本校报考点）
3. **填写信息**：姓名/身份证/学历/专业/联系方式，核对无误（信息影响证书）
4. **上传照片**：白底近期证件照，jpg 格式，按页面规格要求（一般 295×413px 左右，20-50KB），可用平台自带照片处理工具裁剪
5. **选择资格**：中级 → **嵌入式系统设计师**（注意别选成「嵌入式系统开发工程师」之类，官方名称为「嵌入式系统设计师」）
6. **确认提交** → 进入缴费页
7. **在线缴费**（微信/支付宝/网银，按省平台支持方式）
8. **保存报名表**：缴费后生成报名信息表，截图/留存（现场核查偶尔需要）

## 3. 常见坑（前人踩过）

- ⚠️ **错过窗口**：部分省窗口极短（7-10 天），且不补报。→ 报名季每日刷公告
- ⚠️ **照片不合规**：用旧照片/自拍被驳回，耽误时间。→ 提前用证件照工具处理
- ⚠️ **选错科目**：科目列表长，确认选的是「嵌入式系统设计师（中级）」
- ⚠️ **拖到截止日**：系统拥堵、支付失败、审核驳回没有补救时间
- ⚠️ **机考设备**：2023 起全面机考，考试当天提前 30-40 分钟到场，熟悉机房环境
- ⚠️ **证件**：身份证原件 + 准考证，缺一不可

## 4. 考后

- **成绩**：约考后 1.5-2 个月公布，官网首页通知查询
- **合格线**：两科各 ≥45 分（满分 75）；部分艰苦边远地区有单独划线政策（以当年通告为准）
- **领证**：电子证书（人社部电子证书系统）先行可查，纸质证书按本省通知领取/邮寄
- **证书效力**：中级职称（工程师）资格，全国有效、长期有效，可用于职称评定/落户/求职

# 软考 · 嵌入式系统设计师 — 学习路径

**版本**: v1.0 | **日期**: 2026-08-05 | **考试**: 2026-10-24~27（以准考证为准）

---

## 0. 总原则

1. **科班优势变现**：计算机系统基础/软件工程/网络是 AI 专业必修，直接快速过，把时间砸在缺口（嵌入式硬件体系、RTOS）
2. **与 W1/W2 联动**：考纲里的中断/PWM/UART/I2C 正是 W1 实操内容，**实操过的知识点记忆牢度碾压死记硬背**
3. **真题导向**：上午题考广度、下午题考套路，近 5 年真题是唯一的准绳
4. **两科并进**：上午打底（8-9 月），下午专项（10 月），别只刷选择题

## 1. 考纲知识地图（映射你的知识栈）

| 考纲模块 | 知识点 | 你的基础 | 缺口等级 | 学习策略 |
|---------|--------|---------|---------|---------|
| **计算机系统基础** | 数制/编码、存储层次、指令系统、总线、DMA、中断 | 科班课程 ✅ | 🟢 低 | 刷题过，错题回补 |
| **嵌入式微处理器** | ARM 体系（内核/流水线/异常/寄存器）、汇编基础 | 部分（W1 用到但没系统学） | 🔴 高 | 重点：ARM 异常处理 + 汇编阅读，配合 W1 |
| **嵌入式硬件设计** | 存储器（Flash/SRAM/接口时序）、I/O、A/D、接口（UART/I2C/SPI/CAN/USB） | W1 实操过 UART/I2C ✅ | 🟡 中 | 接口部分吃 W1 红利，补 SPI/CAN/USB 原理 |
| **嵌入式操作系统** | RTOS 概念、任务/调度、同步互斥（信号量/消息队列）、中断管理、μC/OS 或 FreeRTOS、嵌入式 Linux | **基本空白** ❌ | 🔴 最高 | **最大失分区，最先攻**：任务三要素/调度算法/优先级反转 |
| **嵌入式软件开发** | 交叉编译、启动流程（Bootloader）、BSP/驱动模型、调试 | 空白 ❌ | 🔴 高 | 理解流程为主，不必真写驱动 |
| **软件工程/网络** | 开发模型、测试、TCP/IP、网络设备 | 科班课程 ✅ | 🟢 低 | 快速过 |
| **安全/可靠性** | 嵌入式安全、抗干扰、看门狗 | 概念级 | 🟡 中 | 背要点，性价比高（出题稳定） |

> **结论**：你的战役在 **ARM 体系 + RTOS + 嵌入式软件流程** 三块，约占总分 40-50%，现在基本空白。科班底子能白拿 20-30%。

## 2. 分阶段计划（8/18 - 10/23，约 9.5 周）

### P0 决策与报名（8/5 - 8/17）
- [ ] 确认本省报考点规则（在校生优先本校报考点）
- [ ] 购教材：《嵌入式系统设计师教程》（清华大学出版社，官方教程）+ 近 5 年真题
- [ ] 注册 bm.ruankao.org.cn 账号，备好白底证件照
- [ ] 每日刷一眼本省软考办公告，报名窗口一开就报（见 `registration.md`）

### P1 上午科目·系统铺面（8/18 - 9/30，6 周 · 8h/周）
| 周 | 主题 | 内容 | 产出 |
|----|------|------|------|
| W1 | 计算机系统基础 | 数制/存储/指令/总线/DMA/中断，刷真题选择 | 错题本#1 |
| W2 | **ARM 体系（重点）** | 内核/流水线/寄存器/异常处理/汇编阅读 | 异常处理流程图（画一遍） |
| W3 | 嵌入式硬件 | 存储器时序/I/O/AD/SPI/CAN/USB 原理，**对照 W1 实操** | 接口对比表 |
| W4 | **RTOS（重点）** | 任务/调度/同步互斥/中断管理/优先级反转 | 手写调度场景分析 5 例 |
| W5 | 嵌入式 Linux + 开发流程 | 交叉编译/Bootloader/BSP/驱动模型/调试 | 启动流程图 |
| W6 | 软件工程+网络+安全 | 快速过 + 看门狗/抗干扰要点 | 错题本#2 |

### P2 下午科目·案例分析专项（10/1 - 10/16，2 周）
- [ ] 下午题题型拆解：系统设计题（画框图/架构）、代码阅读题（C/汇编）、RTOS 设计题（任务划分/同步）、接口设计题
- [ ] 近 5 年下午真题精做（**机考环境练画图**——官方机考模拟系统）
- [ ] 总结答题模板：读题→抓约束→画图→分点作答

### P3 冲刺模考（10/17 - 10/23，1 周）
- [ ] 3 套完整真题限时模考（上午 2h / 下午 2.5h 节奏练）
- [ ] 错题本全面复盘，只补高频失分点
- [ ] 背诵型清单最后过一遍（安全/可靠性/网络）
- [ ] 打印准考证，确认考场交通

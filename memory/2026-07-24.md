### PAK 高压缩率说明

PAK（三雄极光）页面在 markdown 中嵌入了完整侧边导航菜单（~4000 字符），清洗后剩余正文约 2000 字。这是网站结构问题，非规则误杀。约 2000 字的正文是有效的产品方案描述。

### 技术决策

- `noop.image` OSS 防盗链 → 图片下载返回 0 bytes → 标 manual，不阻塞流程
- PAK 详情页导航链（`[导航名](</...>)`）→ 用 `===RM_LINE===` 逐行删除
- 文件名在 merge 后标准化：`{source}_正文.md` 以匹配 clean_text.py 路径规则

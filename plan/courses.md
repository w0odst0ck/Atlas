## A. 嵌入式手感（W1 · 现在）

### 知识栈
| 知识点 | 掌握标准 |
|--------|---------|
| ESP32 GPIO | 点灯/按键，读懂 datasheet 引脚图 |
| 中断 + 防抖 | 能讲清中断原理，写防抖代码 |
| PWM | 示波器看到波形变化，理解占空比/频率 |
| UART | loopback 自发自收，理解波特率/帧格式 |
| I2C | 读 MPU6050（六轴 IMU，Wokwi 无 BME280） |
| 架构认知 | 五层总图 + ADR 决策记录（`../../Forge/w1/architecture/`） |

### 课程资料
| 资料 | 类型 | 链接/位置 |
|------|------|----------|
| Wokwi 仿真 | 实操 | https://wokwi.com（免费零安装，含虚拟示波器） |
| 江协科技 ESP32 教程 | 视频 | B站（中文口碑最佳，GPIO/中断/PWM 全有） |
| ESP-IDF / Arduino 官方文档 | 文档 | espressif.com 官网 |

### 验收
W1 六天任务全过（`tech-plans/4week-awakening.md`），产出复盘笔记。
任务表/进度看板 → `../../Forge/w1/README.md`（状态在 F 仓，A 仓为设计基线）

## B. 协议层（W2-W3 · 最硬能力 🔴）

### 知识栈
| 协议 | 掌握度 | 掌握标准 |
|------|--------|---------|
| **Modbus RTU/TCP** | 🔴 精通 | 能抓包调试，读懂帧结构（地址/功能码/CRC） |
| **RS-485 总线** | 🔴 精通 | 现场组网、终端电阻、常见故障排查 |
| **MQTT** | 🔴 精通 | 发布/订阅、QoS、topic 设计、桥接 |
| DALI | 🟡 熟悉 | 帧结构、三级寻址、DALI-1 vs DALI-2 |
| KNX | 🟡 熟悉 | 三层拓扑、双地址体系、与 DALI 分工 |
| Zigbee / 蓝牙Mesh | 🟡 熟悉 | 组网原理、网关依赖、选型判断 |
| LoRaWAN / OPC UA | 🟡 了解 | 知道适用场景即可 |

### 课程资料
| 协议 | 资料 | 位置 |
|------|------|------|
| Modbus | pymodbus 官方文档 + W2 实操 | https://pymodbus.readthedocs.io |
| RS-485 | 正点原子/江协 RS485 章节 | B站 |
| MQTT | EMQX 官方教程 + HiveMQ Essentials | https://www.emqx.com/zh/blog |
| DALI | Microchip AN3200A + 莱福德 FAQ | `plan/protocols_learning.md` 已收全 |
| KNX | EMQ《KNX协议基础》+ ThingsCloud | `plan/protocols_learning.md` |
| Zigbee/Mesh | 亿佰特详解 + Digi 对比 | `plan/protocols_learning.md` |

> **结论**：协议资料基本齐备，缺的是 W2 实操（com0com 虚拟串口 + pymodbus 主从 + MQTT 桥接）。

### 验收
W2 六天任务全过：主从读写、3 从站寻址、MQTT 桥接、掉线容错。

## C. 软件平台层（W4 起 · 贯穿）

### 知识栈
| 模块 | 选型 | 状态 | 掌握标准 |
|------|------|------|---------|
| 后端 API | FastAPI | ✅ 已有 | REST 设计、异步、WebSocket |

| 场景调度 | 定时任务 + 课表对接 | 🟡 | cron/APScheduler + API 对接 |

### 课程资料
| 模块 | 资料 |

## D. 硬件集成（L1-L3 · 贯穿阶段1-2）

### 知识栈
| 层级 | 内容 | 需要吗 |
|------|------|--------|
| L1 硬件认知 | 看懂规格书（电流/功率因数/纹波/调光范围） | ✅ 必须有 |
| L2 系统设计 | 选型/BOM/给 ODM 提需求清单 | ✅ 必须有 |
| L3 集成调试 | RS-485 调试/故障排查/兼容性 | ✅ 必须有 |
| L4 硬件研发 | 电路/PCB/量产 | ❌ 外包 |

### 课程资料
| 资料 | 位置 |
|------|------|
| W3 驱动芯片 datasheet 精读（晶丰明源/明微） | 厂商官网 |
| 教室灯合规条款 | `tech-plans/classroom_retrofit.md`（RG0/频闪/Ra） |
| 无频闪调光原理 | W3 任务 + 驱动规格书 |
| 现场工具链 | USB-RS485 + 照度计 + 功率计 + 示波器（2000-5000 元预算） |

### 验收
能向 ODM 提一份完整定制需求清单；现场能独立排查 RS-485 通信故障。

## 一页总结

```
现在:   A 嵌入式(Wokwi) + B 协议(pymodbus) + C 平台起步 → W1-W4
半年:   C 深化(时序库) + D 硬件集成 + E 数据变现 → 首个项目
一年半: D/E 成熟 → ESCO 落地 + 网关自研
三年:   F ROS2/CARLA → 自动驾驶仿真平台工程师
```

**原则**：每阶段只专注一个交付物；资料按需采购；协议是护城河，实操优先于读书。

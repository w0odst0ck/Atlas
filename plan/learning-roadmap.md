## Day 0：快速原型（0.5-1 天）

**目的**：先建立"一个照明方案到底长什么样"的直观感受，再看什么都对得上。

**执行**：
1. ⏱ 15分钟：选一个场景（推荐办公），读 `方案馆/office.md` 摘要
2. ⏱ 15分钟：打开 **EEPW 办公照明论文**（`refs/office/eepw/eepw_正文_clean.md`），扫一遍
3. ⏱ 20分钟：**立刻写一页"烂方案"**，假装你要为一个 3000㎡ 办公室出智能照明方案
   - 不用专业，不用准确，不用引用
   - 目的是暴露自己"哪些地方不知道"
4. ⏱ 10分钟：列一个**"我不知道"清单**（至少 5 条），这就是后面积累的靶子

**产出**：
- 一份写得很烂但属于你自己的方案草稿 → `plan/quick_proto.md`
- 一份"我不知道清单" → 每次学到一个新东西回来划掉一条

## 第一阶段：螺旋广度（~5 轮，每轮 1-2 天）

### 轮次安排

| 轮 | 场景 | 原因 | 预计天数 |
|----|------|------|---------|
| 1 | **办公 + 教育** | 最像的两个"室内功能照明"，对比着读效果翻倍 | 1-2 |
| 2 | **酒店 + 博物馆** | 体验导向 vs 精度导向，完全不同的控制逻辑 | 1-2 |
| 3 | **工厂 + 仓储 + 停车场** | 三个都是"大空间节能"逻辑，但协议/传感器完全不同 | 2 |
| 4 | **商业 + 应急 + 厂商总览** | 零售场景特殊 + 应急法规驱动 + 通盘认知 | 2-3 |
| 5 | **户外 + 体育 + 交通 + 地铁 + 房地产** | 剩余场景，"大口吃" | 2 |

### 每轮的标准动作

```
□ 1. 读场景摘要（方案馆/{scene}.md）
□ 2. 读至少 1 篇精洗正文（优先厂商方案）
□ 3. 填场景摘要卡（plan/cards/{scene}.md）
□ 4. 标注 AI 切入点（卡片的第 6 栏）
□ 5. 回去看一眼自己的"烂方案"——现在能改什么了？
```

## 第二阶段：螺旋深度（~2 轮，每轮 2-3 天）

### 核心变化
不再只是"读"，而是**先写再修正**。

### 每轮动作

```
Step 1: 选 1 个场景（选素材最多的，推荐办公或工厂）
Step 2: 读 3 篇该场景素材（厂商 + 论文 + 集成商）
Step 3: 用 plan/phase2-matrix.md 做对比分析
Step 4: 关掉素材，凭记忆写一版"假设方案"
Step 5: 重新打开素材，逐段对照，修正
Step 6: 记录差异——"我哪里想偏了？哪里想对了？"
```

### 为什么这样比"先读再写"好
- 先写再对照 → 大脑主动检索，比被动阅读记忆深 3 倍
- 暴露偏差 → 偏差才是真正的学习点
- 产出和修正交替 → 每轮都得到一版越来越好的方案草稿

### 两轮选什么
| 轮 | 场景 | 重点练习 |
|----|------|---------|
| 1 | **办公** | 需求分析 + 控制策略设计 |
| 2 | **工厂** | 效益测算 + 设备选型 |

## 第三阶段：AI 能力注入（贯穿全过程，第 2 轮结束后集中半天下沉）

### 贯穿动作（每张卡都做）
已在卡片模板中。每读一个场景，想 AI 能改什么。

### 集中动作（Day 15 左右做一次）
把 20 张卡的 AI 想法汇总到 `plan/ai-mapping.md`，补全以下：

| AI 技术栈 | 你用过的技术 | 照明场景应用 | 可行性评估 |
|-----------|------------|-------------|-----------|
| 视觉(CV) | | | |
| 时序预测 | | | |
| 强化学习 | | | |
| LLM/NLP | | | |
| 异常检测 | | | |
| 知识图谱 | | | |
| 多模态 | | | |

这一行的"可行性评估"你可以按自己的技术水平来标注：
- ✅ 现成就能做

- ❓ 方向不确定

## 第四阶段：独立出方案（~1-2 周）

### 和 v1 不同之处
**不再只用素材，还可以用你的 AI 工具链来辅助。**

写方案时你可以（也应该）：
1. **用 LLM 做方案大纲** → 和素材交叉验证
2. **用代码做照明计算** → 程序化生成照度/节电率
3. **用可视化工具** → 出方案里的数据图表
4. **用知识图谱** → 把你的 20 张摘要卡做成可查询的知识库

### 推荐产出的方案
| 方案 | 场景 | 难度 | 说明 |
|------|------|------|------|
| 必写 | 办公 | 中等 | 素材最全，适合练手 |
| 二选一 | 工厂 or 酒店 | 中等偏高 | 重节能 vs 重体验 |
| 三选一 | 任意 P1 场景 | 高 | 素材少，考验"举一反三" |

## v1 → v2 关键变化一览

| 维度 | v1 | v2 |
|------|----|----|
| **学习模式** | 线性瀑布（读→写） | 螺旋（先写→读→修正→深化） |
| **AI 位置** | 第三阶段 | 贯穿全程 + Day 0 标注 |
| **首个产出** | 第 10 天（读完 20 场景） | Day 0（快速原型草稿） |
| **阅读分组** | 逐个场景 | 按逻辑聚类（同类对比读） |
| **修正机制** | 无 | 先写再对照素材修正 |
| **AI 工具辅助** | 无 | 主动建议用 LLM/代码做工具 |
| **重复劳动** | 20 张卡片可能重复 | 同类场景合并轮次 |

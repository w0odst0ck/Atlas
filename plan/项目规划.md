## 四、采集方案

### 4.1 全量采集规范

每来源产出 5 类内容：

| 内容 | 采集方式 | 失败处理 | 产物 |
|------|---------|---------|------|
| 正文文本 | requests + bs4 / playwright | 标 manual | `{source}_正文.md` |
| 原始 HTML | 直接保存 | 自动做 | `{source}_正文.html` |
| 配图 | 提取 img → 下载 | 标 manual | `images/` |
| PDF 附件 | 提取 a[href$=.pdf] → 下载 | 标 manual | `pdfs/` |
| 采集报告 | 自动生成 | 自动做 | `_采集报告.md` |

### 4.2 采集方式分级

| 方式 | 工具 | 适用来源 | 效果 |
|------|------|---------|------|
| 静态采集 | requests + bs4 | 沃思/EEPW/嘉复欣/雷特等 | ✅ 正文完整 |
| 动态采集 | playwright + 系统 Chrome | 三雄极光 PAK 方案页 | ✅ 6000+ 字/页 |
| PDF 下载 | requests 流式 | 厂商图册 | ✅ 能下就下 |
| 手动兜底 | 标注 manual: | 所有自动失败的 | ⏳ 你后续处理 |

## 五、数据清洗与归档

### 5.1 清洗流程

```
采集原始正文 → 规则清洗 → 清洗后正文
```

共 5 条规则：

| 规则 | 处理目标 | 实现方式 |
|------|---------|---------|
| 移除导航 | "首页 > 产品" 面包屑、菜单文字 | 正则 |
| 移除版权 | "©2023 All Rights" 等 | 正则 |
| 空行归并 | 连续 3+ 空行 → 2 空行 | 正则 |
| 移除尾部推荐 | "相关文章""你可能还喜欢" 等 | 正则 |
| 链接修正 | `<>` 多余符号 | 正则 |

### 5.2 归档结构

```
refs/{scene}/
├── 00_场景摘要.md          ← 该场景所有来源一览
├── {source1}/              ← 原始采集文件（不动）
│   ├── {source1}_正文.md
│   ├── {source1}_正文.html
│   ├── {source1}_正文_clean.md  ← 清洗后版本
│   ├── images/
│   ├── pdfs/
│   └── _采集报告.md
└── {source2}/
```

### 5.3 SKU 交叉关联

从 `全部商品.xlsx` 按场景关键词筛选，产出 `{scene}_sku.csv`

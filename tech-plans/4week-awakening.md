## W2：Modbus 主从 + MQTT 桥接（纯 Python）

**工具**: pymodbus + com0com（Windows 虚拟串口）+ EMQX（或 mosquitto）

### 核心概念（30 分钟回顾）

- Modbus RTU：串口帧格式（地址/功能码/数据/CRC）
- 功能码：03 读保持寄存器、06 写单寄存器、16 写多寄存器
- 寄存器映射：把"灯具"建模为寄存器（亮度、状态、地址）

### 任务

| 天 | 任务 | 验证标准 |
|----|------|----------|
| D1 | com0com 创建虚拟串口对（COM3↔COM4） | Python 串口打通 |
| D2 | pymodbus 从站：模拟灯具（保持寄存器=亮度） | 主站能读到 |
| D3 | pymodbus 主站：轮询 + 写亮度 | 读写正确 |
| D4 | 多从站：3 个灯节点不同地址 | 地址码分配正确 |
| D5 | MQTT 桥接：Modbus 数据 → MQTT topic | broker 收到消息 |
| D6 | 掉线模拟：关从站，主站报错 | 异常处理 + 重连 |
| D7 | 复盘 | W2 笔记 |

**产出**: `Forge/digital-twin/` 的雏形代码（灯节点 + 网关）

## W3：调光驱动原理 + 照明领域知识

**工具**: 文档 + 驱动芯片手册（如 BP 系列调光驱动、晶丰明源）

### 必懂概念

| 概念 | 要点 |
|------|------|
| 调光方式 | 0-10V / DALI / PWM / 可控硅前切 |
| 频闪根源 | 低频 PWM 调光 → 频闪（教室红线） |
| 无频闪方案 | 高频 PWM（≥3kHz）或恒流调光（CCR） |
| 恒照度 | 光照传感器 → 闭环调节占空比 |
| 存在型 vs 移动型 | 存在型可检测静止人体（教室必须） |
| 驱动关键参数 | 输出电流/功率因数/纹波/调光范围 |

### 任务

| 天 | 任务 | 验证标准 |
|----|------|----------|
| D1 | 读 1 款调光驱动芯片手册（datasheet） | 能说清调光原理 |
| D2 | 理解 DALI 协议（双线数字寻址调光） | 画出 DALI 帧结构 |
| D3 | 理解 0-10V 模拟调光 | 对比 DALI 优劣 |
| D4 | 画调光系统架构图 | 驱动/灯/传感器/控制器关系 |
| D5 | 阅读教室灯招标合规条款（Atlas 已有） | 对照理解 RG0/频闪/Ra |
| D6 | 梳理"无频闪调光驱动"选型要点 | 给 ODM 提需求清单 |
| D7 | 复盘 | W3 笔记 |

**产出**: `Atlas/retrofit/protocol-notes/` 协议笔记

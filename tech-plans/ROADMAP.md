## 2. 第一阶段：智能化改造项目能力建设（0-6 个月）

### 2.1 4 周零硬件唤醒计划（纯仿真）

| 周 | 内容 | 工具 | 产出 |
|----|------|------|------|
| W1 | 嵌入式手感唤醒 | Wokwi（ESP32 + 示波器） | PWM/UART/GPIO 找回 |
| W2 | Modbus 主从 + MQTT 桥接 | pymodbus + com0com 虚拟串口 | 真实 Modbus RTU 帧跑通 |
| W3 | 调光驱动原理 + 照明领域知识 | 驱动芯片手册 + DALI/0-10V | 与 ODM 对话的底气 |
| W4 | 系统 POC | BOM 引擎 + 方案库 | 完整方案输出能力 |

### 2.2 技术栈定位

```
你 = 协议能力(Modbus/RS-485/MQTT) + 软件平台(FastAPI/时序库)
   + 数据审计(pandas) + 硬件集成(L1-L3) + 供应链整合
```

- **核心自研**：网关/协议转换（技术护城河，有嵌入式基础所以敢自研）
- **采购 ODM**：灯具、驱动、传感器
- **外包**：施工安装、前端界面
- **明确不碰**：L4 硬件研发制造（电路设计/PCB/量产）

### 2.3 关键里程碑

- [ ] M1: 4 周仿真计划完成（协议栈跑通）
- [ ] M2: 照明数字孪生框架 v1（灯具模拟 + 网关 + 平台 + Web 面板）
- [ ] M3: 接触 2-3 家灯具 ODM，完成一轮定制需求沟通
- [ ] M4: 产出完整教室改造方案（含投标合规清单）

## 3. 第二阶段：数字孪生深化 + 项目落地（6-18 个月）

### 3.1 数字孪生项目（lighting-digital-twin）

```

可视化: Web 面板（平面图 + 灯具状态 + 能耗曲线 + 场景动画）
```

## 4. 第三阶段：汽车/自动驾驶切入（18-36 个月）

### 4.1 技术路径

| 阶段 | 内容 | 工具 |
|------|------|------|
| 入门 | 自动驾驶仿真环境 | **CARLA + ROS 2**（3060 双机够跑） |
| 进阶 | 多车协同/交通流 | SUMO + ROS 2 |
| 地基 | 车载通信 | CAN 总线（CANoe 试用版 / 虚拟 CAN） |
| 深化 | 感知/规划/仿真平台 | NVIDIA DRIVE Sim / 自建仿真工具链 |

### 4.2 定位选择

- **仿真平台工程师**：开发/维护自动驾驶仿真测试平台（岗位存在且稀缺）
- **感知/规划算法**：需要更深的 AI 基础（结合数据科学背景可行）
- **车载软件架构**：ROS 2 经验直接迁移

### 4.3 硬件规划

- 双 3060 主机：一台跑 CARLA 仿真，一台跑 ROS 2 + 数据处理（或 SLAM 相关）
- 后期按需升级（4090 / 云 GPU）

### 4.4 关键里程碑

- [ ] CARLA + ROS 2 跑通"车辆 + 传感器 + 简单规划"demo
- [ ] 完成一个小型自动驾驶仿真项目（如车道保持 / 避障）
- [ ] 建立汽车领域知识库（接续 study-vault 10-12 月自动驾驶规划）

## 5. 风险与边界

| 风险 | 对策 |
|------|------|
| 照明项目落地周期长 | 先跑通仿真 POC 再谈项目，不空转 |
| 汽车领域竞争激烈 | 用"仿真 + 集成"差异化，不硬卷算法 |
| 量化主业与扩展线冲突 | 串行推进：照明为当前主线，汽车为远期，量化保持 |
| 技术广度铺太开 | 每阶段只专注一个交付物（POC → 项目 → demo） |

# 教室灯智能化改造技术方案

**版本**: v1.0  
**日期**: 2026-07-31  
**定位**: 在健康照明合规（CCC/RG0/频闪/Ra≥90）底线之上，叠加智能化增值层

---

## 1. 方案概述

### 1.1 背景

教室照明已从"亮不亮"进入"健不健康 + 智不智能"双标准时代：

- **合规底线**（采购硬门槛）：CCC 认证、IP40+、Ra≥90/R9≥90、RG0 蓝光、无频闪、上射光≥10%
- **增值层**（差异化竞争）：恒照度、课表联动、分区控制、能耗管理

本方案回答一个问题：**在不动摇健康照明认证的前提下，把普通教室灯改造为智能教室灯。**

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **合规优先** | 任何智能化特性不得破坏 RG0/频闪/Ra90/CCC 认证 |
| **场景专属** | 教室 ≠ 车库：存在型雷达、课表联动、档位调光 |
| **成本可控** | 有限档位调光替代连续调光，降本降风险 |
| **模式可复制** | 支持政府采购/ESCO/私立校三种商业模式 |

---

## 2. 改造路径决策

| 路径 | 做法 | 成本 | 合规风险 | 适用 |
|------|------|------|----------|------|
| **A 整灯替换** ✅ | 直接采购智能教室灯，新品完整走认证 | 高 | 低 | 政府采购/新建 |
| **B 加装智控盒** | 原灯+外置控制/感应模块 | 低 | 高（CCC 重新评估） | 私立校低预算 |
| **C 混合分期** | 部分替换+新增网关 | 中 | 中 | 分期过渡 |

**推荐 A**。B 路径的坑：灯体改动后 CCC 认证需重新评估，投标验收时报告对不上。

### 2.1 商业模式：ESCO 合同能源管理

学校普遍无改造预算，这是项目能否落地的第一决策点：

```
第三方（ESCO）出资改造
      ↓
学校零投入，立即享受节能收益
      ↓
合同期 5-8 年，用节能收益分期还款
      ↓
合同期满，设备无偿移交学校
```

适用场景：公立校财政紧张、节能收益可量化（恒照度+课表联动通常节能 40-60%）。

## 3. 系统架构

```
┌─────────────────────────────────────────────────────────┐
│ 终端层  智能教室灯（600×600 面板）                        │
│         光源: 5000K±200K / Ra≥90/R9≥90 / RG0 灯珠        │
│         光学: 微晶防眩板 + 上射光结构(≥10%)               │
│         驱动: 无频闪调光驱动（≥3kHz 高频 / 离散档位）     │
│         传感: 存在型雷达 + 光照传感器                     │
└──────────────────────┬──────────────────────────────────┘
                       │ RS-485 总线（教室内部 20-30 盏）
┌──────────────────────▼──────────────────────────────────┐
│ 网络层  教室网关（LoRa / 以太网上行）                     │
│         楼层汇聚 → 校园网 → 云平台                        │
└──────────────────────┬──────────────────────────────────┘
                       │ 4G/Wi-Fi/以太网
┌──────────────────────▼──────────────────────────────────┐
│ 平台层  教室照明管理云 / 本地服务器                       │
│         恒照度 / 课表联动 / 分区 / 能耗 / 告警            │
└─────────────────────────────────────────────────────────┘
```

### 3.1 三级混合拓扑（成本最优）

```
教室内部: RS-485 总线（成本最低，一室一线）
楼层:     网关汇聚（LoRa/以太网，穿墙佳）
校园:     4G/Wi-Fi 上云
```

## 4. 智能功能设计

### 4.1 恒照度控制（节能第一单点）

- 光照传感器（每教室 1 个，吊顶中央）实时检测桌面照度
- 自然光充足 → 自动降档补光；阴天/傍晚 → 升档
- **离散档位调光**（100% / 70% / 40% / 10%）替代连续调光：
  - 驱动成本更低
  - 避开低频 PWM 频闪区
  - 节能 30-50%

### 4.2 课表联动（教室专属节能逻辑）

教室与车库的本质区别：**上课时间恒定有人，雷达白耗**。

```
对接教务课表系统
  ├─ 上课时段 → 恒照度模式
  ├─ 课间     → 70% 亮度
  ├─ 午休/自习 → 分区（靠窗关、靠墙 40%）
  └─ 放学/周末 → 10% 休眠档 / 全关
```

### 4.3 存在型雷达感应（关键选型）

⚠️ **移动型雷达检测不到静止的学生**（上课场景会误灭灯）。

- 必须选 **存在型雷达**（检测微动+呼吸）
- 用于：放学后无人自动关灯、周末巡检、安防联动
- 与课表联动互为补充，不重复

### 4.4 分区独立控制

```
黑板灯（独立回路，需单独调光）
讲台区（教师移动频繁，感应优先）
学生区（按排分区，恒照度为主）
```

### 4.5 场景模式

| 模式 | 黑板灯 | 学生区 | 适用 |
|------|--------|--------|------|
| 上课 | 100% | 100% | 常规授课 |
| 投影 | 关闭 | 40% | 多媒体教学 |
| 自习 | 70% | 100% | 阅读写作 |
| 考试 | 100% | 100% | 高均匀度 |
| 放学 | 关闭 | 10% | 节能休眠 |

### 4.6 应急照明联动

教室灯兼做应急灯（带应急电源模块），消防验收刚需，一个增量点。

### 4.7 校园能源平台（扩展）

照明 + 空调 + 风扇联动："放学一键关全校"。从照明方案升级为校园能源方案。

## 5. 合规红线

| 红线 | 风险点 | 对策 |
|------|--------|------|
| 频闪 | 普通 PWM 调光低亮度产生频闪 | 无频闪驱动（≥3kHz 或离散档位） |
| RG0 | 调光过程蓝光比例漂移 | RG0 认证灯珠，调光不降级 |
| Ra≥90 | 调光掉显色 | 驱动电流范围约束，Ra 全程达标 |
| CCC | 外置模块改动灯体 | 整灯替换 or 智控盒不做机械改动 |

### 5.1 检测报告前置（里程碑 0）

招标要求"CMA/CNAS 报告 + 查询截图 + 盖章 + 签合同时提供"，报告周期 1-2 个月。

**必须投标前备好**，列为项目里程碑 0，而非发货前才想起。
